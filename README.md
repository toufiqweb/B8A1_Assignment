# B8A1 - Problem Solving with TypeScript & OOP

## Overview

This assignment is about practicing the main TypeScript topics from Modules 1, 2 and 3. It has two parts: coding problems and blog posts.

## Problem Solving

All 8 solutions are in [solutions.ts](./solutions.ts). The problems cover:

- Optional parameters (`multiplyValue`)
- Union types and type narrowing (`processInput`)
- Readonly tuples (`formatCoordinate`)
- Generics with rest parameters (`concatenateArrays`)
- Interfaces and filtering arrays (`Course`, `getPopularCourses`)
- Generics with `keyof` (`pluckValues`)
- Classes, inheritance and access modifiers (`Employee`, `Manager`)
- Promises with `setTimeout` (`validateAgeAsync`)
